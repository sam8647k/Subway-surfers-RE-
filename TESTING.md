# Manual test checklist

- [ ] Open `index.html` in a modern browser.
- [ ] Start the game and confirm the score increases.
- [ ] Move left and right using keyboard arrows.
- [ ] Jump over a barrier using Up or the jump button.
- [ ] Roll under a sign using Down or the roll button.
- [ ] Collect a coin and confirm the coin counter increases.
- [ ] Hit an obstacle and confirm the game-over overlay appears.
- [ ] Restart and confirm a new run begins.
- [ ] Confirm the best score persists after refreshing.
- [ ] On a touchscreen, test swipe controls and on-screen buttons.
