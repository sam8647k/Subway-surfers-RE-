# References and source register

Record technical references, public documentation, papers, tool manuals, and lawful sample provenance.

For each source include:
- Stable title and publisher/author
- Canonical URL or bibliographic identifier
- Publication/version date and access date
- Specific claim or method supported
- Relevant page/section/commit
- Limitations, version mismatch, or conflicting sources

Prefer primary documentation and reproducible artefacts. A reference is not proof of behaviour in a particular game build unless it directly supports that claim. Do not link leaked source code or unauthorized asset dumps.
