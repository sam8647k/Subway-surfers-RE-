# Rail Rush — Endless Runner

An original browser-based three-lane endless runner prototype. It uses original canvas-drawn placeholder art and does not include Subway Surfers source code or proprietary assets.

## Run
Open `index.html` in a modern browser, or serve this folder with any static HTTP server.

## Controls
- Left / Right arrows: change lanes
- Up arrow: jump over barriers
- Down arrow: roll under signs
- Swipe on touchscreens, or use the on-screen controls
- Space: start or restart

## Features
- Three lanes, moving obstacles, trains, and collectible coins
- Score, coin counter, and locally saved best score
- Increasing game speed and restart flow
- Responsive layout for desktop and mobile
