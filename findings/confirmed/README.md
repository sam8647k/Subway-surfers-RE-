# Research area

Use this directory for evidence-backed research artefacts relevant to its name.

For every record, identify the target application version/build and platform; record sample hashes, acquisition provenance, tools and versions, method, raw observation, supporting evidence, reproduction steps, limitations, and confidence. Separate direct observations from interpretation. Do not commit proprietary application packages, binaries, extracted assets, credentials, or personal data.

See [the research methodology](../../docs/methodology.md) for evidence classification and reporting requirements.
